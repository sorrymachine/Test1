# 1С конфигурация с нуля (шаблон репозитория)

Этот репозиторий — стартовая заготовка, чтобы создать **конфигурацию 1С “с нуля”** и хранить её в **git в виде исходников (выгрузка в файлы)**.

## Что здесь будет лежать

- `1c/src/` — выгруженная конфигурация 1С “в файлы” (то, что реально версионируем).
- `docs/1c-from-scratch.md` — пошаговая инструкция: как создать пустую конфигурацию и настроить выгрузку/загрузку.

## Быстрый старт

Открой `docs/1c-from-scratch.md` и следуй инструкции под твой сценарий:

- **Designer** (тонкий/толстый клиент): создать ИБ → создать конфигурацию → включить хранилище “в файлах” через *Сохранить конфигурацию в файлы*.
- **EDT**: создать проект → импортировать/выгрузить исходники → работать через git.
